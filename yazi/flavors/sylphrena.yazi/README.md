# Sylphrena Flavor for Yazi

**Sylphrena** is a Cosmere (Stormlight Archive / Honorspren Mist) inspired dark color flavor for [Yazi](https://github.com/sxyazi/yazi).

## Installation

### Using `ya pack` (Recommended)

```bash
ya pack -a Aaravshah2907/sylphrena
```

### Manual Installation

Clone or copy this directory to your Yazi flavors directory:

```bash
mkdir -p ~/.config/yazi/flavors/sylphrena.yazi
# Copy flavor.toml, LICENSE, and README.md into ~/.config/yazi/flavors/sylphrena.yazi/
```

Then configure `~/.config/yazi/theme.toml`:

```toml
[flavor]
use = "sylphrena"
```

## Color Palette

- **Primary Mist Cyan**: `#7FDBFF`
- **Secondary Bright Ice**: `#A8ECFF`
- **Accent Soft Violet**: `#C9B8FF`
- **Mint Spren**: `#8FE7C0`
- **Stormlight Gold**: `#E7D37A`
- **Highstorm Coral**: `#F08AA3`
- **Abyssal Background**: `#031521` / `#071E2D`
